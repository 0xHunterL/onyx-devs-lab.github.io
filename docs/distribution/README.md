## 发布规则

- 每个平台只发布一篇完整首发，其余平台采用不同开头、案例或摘要，避免机械复制。
- 保留作者、机构、发布日期、项目边界和官网深层链接。
- 不购买虚假提及、不伪造客户背书、不把受控样本指标写成普遍承诺。
- 发布后记录公开 URL、平台、日期、收录状态和带来的品牌查询变化。

建议署名：`Onyx Devs Lab｜企业 AI 咨询、定制开发与 FDE 团队`。
